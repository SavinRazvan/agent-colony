# Plugin assets

Marketplace logotype for **MAS Workflow Kit** (referenced from `.cursor-plugin/plugin.json`).

## Add your logo

Place **`logo.png`** or **`logo.svg`** here (1:1 aspect ratio, recommended 512×512 or 1024×1024 PNG on a solid background plate).

After commit to `main`, the marketplace **Logotype URL** is:

```text
https://raw.githubusercontent.com/SavinRazvan/mas-workflow-kit/main/assets/logo.png
```
